## 생산 공정 흐름

```
수주·견적 → 원자재 입고/보관 → 포밍(절곡) → 용접 → 포장 → 보관/출하
```

- **코일 투입 → 피딩 → 타공 → 성형(포밍) → 용접 → 절단** 순서의 다단계 연속 공정
- 제품별 CAD 도면(DWG/PDF) 기반 주문 생산 방식

## 프로젝트 목표

수주·견적–입고–생산–출하 전 공정을 연결하는 **데이터 기반 제조AI 스마트공장** 구축.

| 방향 | 내용 |
|------|------|
| 견적 자동화 | CAD 도면 기반 AI 자동 견적 산출 (리드타임 수시간 → 수분) |
| 생산 가시성 | IoT/PLC 기반 실시간 공정 데이터 수집 및 통합 |
| 품질 안정화 | LOT 기반 Traceability 및 AI Agent 품질 대응 |
| 납기 대응력 | 출하 AI Agent를 통한 납기 리스크 실시간 분석 |

## AI 적용 공정 요약

| 공정 | AI 기술 | 적용 내용 |
|------|---------|-----------|
| 수주·견적 | CAD Parsing + YOLOv8 + GNN + XGBoost + SHAP | 도면 자동 분석, BOM·견적 자동 산출 |
| 입고/보관 | RAG 기반 AI Agent (LLM + Vector DB) | 자재 이력 조회, 품질 판단, 재고 분석 |
| 보관/출하 | RAG 기반 AI Agent (LLM + Vector DB) | LOT 추적, 출하 승인, 클레임 대응 |
| 포밍·용접 | IoT + PLC 데이터 수집 | 공정 데이터 축적 (향후 AI 확장 기반) |
