# 부영기업 현황 문제 분석

## 1. 산업 환경 변화 — 외부 압력

- 금속가공·구조재 제조 산업은 건축·통신·태양광 인프라와 밀접 연계되어 **품질·납기 경쟁력**이 기업 생존의 핵심 요소로 부상
- 금속 프로파일 제품의 치수 정밀도, 구조 안정성, 용접 품질 기준이 지속 고도화됨
- 다품종 소량 생산, 납기 단축, 맞춤형 제품 증가로 **생산·품질·출하 관리 복잡도** 급증
- CAD 도면 기반 주문 생산에서 **설계-견적-생산 간 데이터 연계 부족**이 수주 경쟁력 저하 원인

## 2. 공정별 현재 문제 (AS-IS)

### 수주·견적

| 문제 | 영향 |
|------|------|
| CAD 도면을 작업자가 수작업으로 해석하여 자재·공정·공수 산정 | 견적 리드타임 1일 이상 소요 |
| 담당자 경험·숙련도에 따라 견적 결과 편차 발생 | 원가 오류, 수주 경쟁력 저하 |
| 과거 견적 데이터와 도면 정보가 연계되지 않음 | 반복 업무에도 학습 효과 없음 |
| 설계-BOM-공정-원가 데이터 통합 없음 | 견적-수주-생산 디지털 연계 단절 |

### 입고·보관

| 문제 | 영향 |
|------|------|
| 자재 입고·검사 정보 수기/단순 입력 관리 | 데이터 정합성·실시간 재고 가시성 부족 |
| LOT·물성·재고 정보가 공정 데이터와 미연계 | 품질 추적 및 원인 분석 불가 |
| 작업자 경험에 의존한 자재 보관 위치 관리 | 생산 중 자재 부족/과잉 재고 발생 |

### 포밍 공정

| 문제 | 영향 |
|------|------|
| 속도·압력·금형 조건을 작업자가 경험 기반으로 수동 설정 | 공정 데이터 미수집, 품질 편차 반복 |
| 실시간 설비 모니터링 체계 부재 | 품질 편차 발생 시 원인 분석 불가 |
| 초기 불량 및 시행착오 지속 발생 | 생산 효율 저하 |

### 용접 공정

| 문제 | 영향 |
|------|------|
| 숙련 작업자 경험에 의존한 로봇·수작업 용접 | 작업 완료 여부를 수기/구두로만 관리 |
| 용접 전류·전압·속도·가스유량 등 공정 데이터 미수집 | 불량 발생 시 원인 공정·조건 추적 불가 |
| 품질 데이터와 공정 데이터 미연계 | LOT별 품질 추적 체계 부재 |

### 포장

| 문제 | 영향 |
|------|------|
| 포장 수량·작업 실적 수기 집계 | 생산 실적과 포장 완료 수량 간 오차 발생 |
| 포장 완료 여부 실시간 확인 불가 | 출하 준비 및 납기 대응 비효율 |

### 보관·출하

| 문제 | 영향 |
|------|------|
| LOT 및 출하 이력 체계적 미관리 | 긴급 출하 대응 및 클레임 이력 추적에 많은 시간·인력 소요 |
| 출하 현황·납기 상태·재고 위치 실시간 파악 불가 | 납기 지연, 고객 신뢰도 저하 |
| 출하 전 품질 검증이 수작업·샘플 검사 중심 | 불량 유출 가능성 존재 |

## 3. 데이터 구조 문제

```
현재 상태:
  ERP (일부 운영) ──┐
  현장 수기 기록 ────┤──► 데이터 단절 → 실시간 의사결정 불가
  Excel 관리 ────────┘

문제:
  - 생산·품질·설비 데이터 분산 관리
  - 공정 간 데이터 연결 없음
  - CAD 도면 ↔ BOM ↔ 공정 ↔ 원가 ↔ 출하 연계 부재
  - LOT 기반 입고-생산-출하 Traceability 미흡
```

## 4. 핵심 문제 요약

| 영역 | 핵심 문제 |
|------|-----------|
| 견적 | 수작업 기반, 리드타임 길고 담당자별 편차 |
| 공정관리 | 경험 의존 운영, 공정 데이터 미수집 |
| 데이터 통합 | ERP-현장 데이터 실시간 미연계, 가시성 부족 |
| 이력관리 | LOT 기반 Traceability 체계 미흡 |
| AI 확장성 | 데이터 축적 체계 부재로 제조AI 적용 기반 없음 |
